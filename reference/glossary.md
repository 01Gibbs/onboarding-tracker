# Glossary

The words this course uses, A to Z. **Day** is when the term first matters (Day 0 is the Onboarding Tracker workshop). Link to a term from anywhere with `glossary.md#<id>`, for example [`glossary.md#idor`](#idor).

| Term | Meaning | Day |
|---|---|---|
| <a id="401-vs-403"></a>**401 vs 403** | 401 Unauthorized = "I don't know who you are" (no or wrong login). 403 Forbidden = "I know who you are, and you may not do this" (wrong role). [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#name-401-unauthorized) | 14 |
| <a id="409-conflict"></a>**409 Conflict** | The request clashes with the resource's current state. Here: two transfers updated the same account at once, so retry. [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/409) | 20 |
| <a id="422-unprocessable-content"></a>**422 Unprocessable Content** | The request is well-formed but can't be processed as sent. Here: an idempotency key reused with a different request. [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/422) | 21 |
| <a id="accepted-risk"></a>**Accepted risk** | A known finding you deliberately don't fix yet, with a written reason someone could challenge, and a condition for revisiting it. | 9 |
| <a id="actuator"></a>**Actuator** | Spring Boot's built-in operational endpoints under `/actuator` (health, info, env, heapdump…). Expose only what monitoring needs: `health,info`. [Docs](https://docs.spring.io/spring-boot/reference/actuator/endpoints.html) | 10 |
| <a id="advisory"></a>**Advisory** | A published notice that a library version has a vulnerability, usually with a CVE id, affected versions and the fixed version. Scanners match your versions against advisories. | 8 |
| <a id="allow-list"></a>**Allow-list** | Accept only values from a known-good list (e.g. sort columns `balance` or `owner`) rather than trying to block bad ones. Used where a value can't be a bound parameter. | 16 |
| <a id="api-jar-vs-implementation"></a>**API jar vs implementation** | An API jar holds the interfaces you compile against (`jakarta.xml.bind-api`); the implementation does the work at run time (`jaxb-runtime`). Hence `implementation` for one and `runtimeOnly` for the other. | 25 |
| <a id="application-server"></a>**Application server** | A separate program (Tomcat, WebLogic, WebSphere) that hosts deployed [WARs](#war) and starts them. | 30 |
| <a id="arrange-act-assert"></a>**Arrange / Act / Assert** | The shape of a readable test: set up the inputs and fakes, call the one thing under test, then check the result. | 4 |
| <a id="assertj"></a>**AssertJ** | The assertion library in Spring Boot's test starter: `assertThat(x).isEqualTo(y)`, `isEqualByComparingTo("10.00")` for money. [Docs](https://assertj.github.io/doc/) | 4 |
| <a id="audit-log"></a>**Audit log** | A record of security-relevant events: who, what, when, why (e.g. `LOGIN_FAILED user=ada reason=BadCredentialsException`). Ours is the `security.audit` logger. Never log passwords. [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html) | 18 |
| <a id="authentication"></a>**Authentication (Spring Security)** | Who is calling. Spring passes the logged-in user to a controller method that declares an `Authentication` parameter: `getName()` is the username, `getAuthorities()` the roles. | 15 |
| <a id="base-image"></a>**Base image** | The image named in `FROM`, which your image is built on top of. Its Java runtime and OS packages ship with your app, so they need patching too. | 28 |
| <a id="bean"></a>**Bean** | An object Spring creates and manages for you, e.g. a class marked `@Service` or a `@Bean` method's result. [Docs](https://docs.spring.io/spring-framework/reference/core/beans/introduction.html) | 0 |
| <a id="bigdecimal"></a>**`BigDecimal`** | Java's exact decimal number. Use it for money, never `double`. Build it from a String: `new BigDecimal("10.50")`. See [Java idioms](java-idioms.md#bigdecimal-for-money). | 1 |
| <a id="blast-radius"></a>**Blast radius** | How much of the estate a single problem reaches: here, every service that ships the vulnerable jar, directly or not. | 27 |
| <a id="bom"></a>**BOM (bill of materials)** | A list of library versions known to work together, published as a POM. Spring Boot's is `spring-boot-dependencies`; it also imports other BOMs, such as Jackson's. [Maven](https://maven.apache.org/guides/introduction/introduction-to-dependency-mechanism.html) | 24 |
| <a id="bound-parameter"></a>**Bound parameter** | A query placeholder (`?` or `:name`) whose value is sent separately from the SQL, so input is always data and never code. The fix for [injection](#injection). | 16 |
| <a id="checked-exception"></a>**Checked vs unchecked exception** | A checked exception (`Exception`, `IOException`) must be caught or declared with `throws`. An unchecked one (`RuntimeException` and subclasses) needn't be. Our own exceptions are unchecked. | 1 |
| <a id="classic-starters"></a>**Classic starters** | `spring-boot-starter-classic` / `spring-boot-starter-test-classic`: a temporary Boot 4 option that puts every module back on the classpath, so an old app compiles while you migrate. A step, not a destination. | 29 |
| <a id="constructor-injection"></a>**Constructor injection** | Getting dependencies as constructor parameters into `final` fields, instead of `@Autowired` on fields. Easy to test, impossible to forget. [Docs](https://docs.spring.io/spring-framework/reference/core/beans/dependencies/factory-collaborators.html#beans-constructor-injection) | 3 |
| <a id="controller"></a>**Controller** | The web layer: a `@RestController` class that maps HTTP requests to Java methods (`AccountController`). It shouldn't hold business rules. | 0 |
| <a id="csrf"></a>**CSRF** | Cross-Site Request Forgery: a malicious site makes the victim's browser send a request with their cookies. Spring Security blocks unsafe methods without a CSRF token (403); our stateless HTTP Basic API turns that off. [Docs](https://docs.spring.io/spring-security/reference/servlet/exploits/csrf.html) | 14 |
| <a id="cve"></a>**CVE** | Common Vulnerabilities and Exposures: a public id for one vulnerability, e.g. CVE-2022-1471 (SnakeYAML). [cve.org](https://www.cve.org/About/Overview) | 8 |
| <a id="daemon-jvm"></a>**Daemon JVM** | The JDK that runs Gradle itself, as opposed to the [toolchain](#toolchain) that compiles your code. Legacy days pin it to JDK 17 in `gradle/gradle-daemon-jvm.properties`. [Gradle](https://docs.gradle.org/current/userguide/gradle_daemon.html#sec:daemon_jvm_criteria) | 6 |
| <a id="data-minimisation"></a>**Data minimisation** | Collect, show, log and keep only the personal data you need. Masking an account number to `****5678` is one example. | 23 |
| <a id="defence-in-depth"></a>**Defence in depth** | More than one layer of protection, so one mistake isn't enough to expose something. Here: don't expose an actuator endpoint *and* require a login for it. | 10 |
| <a id="deny-by-default"></a>**Deny by default** | Everything needs permission unless explicitly opened. In Spring Security: `.anyRequest().authenticated()` as the last rule. OWASP A01's first recommendation. | 14 |
| <a id="dependency-injection"></a>**Dependency injection (DI)** | Spring hands an object the other objects it needs (its dependencies) instead of the object creating them with `new`. | 0 |
| <a id="digest"></a>**Digest** | A content hash (`@sha256:…`) that names one exact image forever. Pinning to it makes builds repeatable, but you stop getting fixes until someone bumps it. | 28 |
| <a id="dispatcher-type"></a>**Dispatcher type** | Why a request reached a servlet: a normal request, a forward, or an `ERROR` dispatch to `/error`. Spring Security 6 authorizes error dispatches too, which turned a 404 into a 401 on Day 11. | 11 |
| <a id="dto"></a>**DTO** | Data Transfer Object: the shape of a request or response (`CreateAccountRequest`, `AccountResponse`), kept separate from the [entity](#entity) so the database never becomes the public contract. | 1 |
| <a id="effective-pom"></a>**Effective POM** | Your `pom.xml` after Maven has merged in every parent and BOM: the build Maven actually runs. `./mvnw help:effective-pom` prints it. [Maven](https://maven.apache.org/plugins/maven-help-plugin/effective-pom-mojo.html) | 24 |
| <a id="embedded-server"></a>**Embedded server** | A web server (here Tomcat) packed inside the app, so the app starts itself with `java -jar` or `bootRun`, with no [application server](#application-server). | 30 |
| <a id="end-of-support"></a>**End of support** | The date after which a version gets no more free fixes, security fixes included. Spring Boot 2.7: 2023-06-30; 3.5: 2026-06-30. [spring.io](https://spring.io/projects/spring-boot#support) | 6 |
| <a id="entity"></a>**Entity** | A class mapped to a database table with `@Entity` (`Account` → `ACCOUNT`). [Spring Data JPA](https://docs.spring.io/spring-data/jpa/reference/jpa/entity-persistence.html) | 0 |
| <a id="event-listener"></a>**`@EventListener`** | Marks a method Spring calls whenever a matching event is published, e.g. Spring Security's failed-login events. | 18 |
| <a id="exception-handler"></a>**Exception handler** | A `@RestControllerAdvice` class (`ApiExceptionHandler`) whose `@ExceptionHandler` methods turn exceptions into HTTP responses. New exceptions get a handler here. | 1 |
| <a id="fail-closed"></a>**Fail closed** | When something goes wrong, end in the safe state: check everything before changing anything, and refuse rather than half-do. | 19 |
| <a id="false-positive"></a>**False positive** | A finding the tool reported that isn't really a problem. You still record why, with evidence, so the next scan's reviewer doesn't redo the work. | 26 |
| <a id="filter-chain"></a>**Filter chain (Spring Security)** | The `SecurityFilterChain` bean: filters that run *before* any controller and check the login and the URL rules. Rejected requests never reach your code. [Docs](https://docs.spring.io/spring-security/reference/servlet/architecture.html) | 14 |
| <a id="gradle-wrapper"></a>**Gradle wrapper** | `./gradlew`: a script in each project that downloads and runs the exact Gradle version the project needs. Always use it, never a global `gradle`. [Gradle](https://docs.gradle.org/current/userguide/gradle_wrapper.html) | 0 |
| <a id="h2"></a>**H2** | An embedded Java database. Ours is a file under `data/`; delete the folder to reset it. H2 2.x can't read files written by H2 1.4. | 0 |
| <a id="hashing-vs-encryption"></a>**Hashing vs encryption** | Hashing is one-way (you can check a password, never read it back); encryption is two-way (with the key you get the data back). Store passwords as hashes. [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) | 17 |
| <a id="http-basic"></a>**HTTP Basic** | Login by sending `Authorization: Basic base64(user:password)` on every request. Fine over HTTPS for an API; no session. | 14 |
| <a id="idempotency-key"></a>**Idempotency key** | A unique client-chosen header value (`Idempotency-Key`) that lets the server recognise a retried request and not, say, move money twice. [IETF draft](https://datatracker.ietf.org/doc/draft-ietf-httpapi-idempotency-key-header/) | 20–23 |
| <a id="idempotent"></a>**Idempotent** | Doing it twice has the same effect as doing it once. `GET`, `PUT` and `DELETE` are idempotent by definition; `POST` isn't. [MDN](https://developer.mozilla.org/en-US/docs/Glossary/Idempotent) | 1 |
| <a id="idor"></a>**IDOR** | Insecure Direct Object Reference: changing an id in the URL (`/accounts/2`) reaches someone else's data because nothing checks ownership. Fix: check the owner in the service. [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Insecure_Direct_Object_Reference_Prevention_Cheat_Sheet.html) | 15 |
| <a id="image-tag"></a>**Image tag** | The label after the `:` in an image name (`21-jre-resolute`). Some tags move to newer patches; some never change. | 28 |
| <a id="importresource"></a>**`@ImportResource`** | Loads XML bean definitions into a Java-configured (Boot) app, so you can migrate a big XML app in steps. [Spring Boot](https://docs.spring.io/spring-boot/docs/2.7.18/reference/htmlsingle/#using.configuration-classes.importing-xml-configuration) | 30 |
| <a id="injection"></a>**Injection** | Input that becomes part of a command, e.g. a JPQL query (JPA's SQL-like language) built with `+` where `GBP' OR '1'='1` returns every account. Fix: [bound parameters](#bound-parameter). [OWASP A05](https://top10.owasp.org/2025/A05_2025-Injection/) | 16 |
| <a id="iso-4217"></a>**ISO 4217** | The standard three-letter currency codes (`GBP`, `EUR`, `USD`) and their minor units (2 decimals for GBP, 0 for JPY). Java: `java.util.Currency`. [Maintenance agency (SIX)](https://www.six-group.com/en/products-services/financial-information/market-reference-data/data-standards.html) | 3 |
| <a id="jackson-3"></a>**Jackson 3** | The new major version of the JSON library Spring uses (Boot 4). Its group id and packages moved from `com.fasterxml.jackson` to `tools.jackson`. | 24 |
| <a id="jakarta-vs-javax"></a>**Jakarta vs javax** | Java EE's packages (`javax.persistence`, `javax.validation`) were renamed `jakarta.*`. Boot 2.x uses `javax`, Boot 3+ `jakarta`: the biggest mechanical change in a Boot 3 upgrade. | 6 |
| <a id="java-version-string"></a>**Java version string** | Java 8 reports itself as `1.8.0_504`; from Java 9 the version looks like `11.0.33` ([JEP 223](https://openjdk.org/jeps/223)). Code that parses `1.x` breaks on 11. | 25 |
| <a id="jaxb"></a>**JAXB** | Java Architecture for XML Binding: turns Java objects into XML and back, using annotations like `@XmlRootElement`. Inside the JDK up to Java 10; a separate library since Java 11. [Eclipse JAXB](https://eclipse-ee4j.github.io/jaxb-ri/) | 25 |
| <a id="jdeps"></a>**jdeps** | A JDK tool that lists a jar's dependencies; `jdeps --jdk-internals` finds code using JDK internals that may break on a newer JDK. [Docs](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jdeps.html) | 13 |
| <a id="jep"></a>**JEP** | JDK Enhancement Proposal: the document behind each Java feature or change, e.g. JEP 451 (warnings about dynamically loaded agents). [openjdk.org/jeps](https://openjdk.org/jeps/0) | 13 |
| <a id="jep-320"></a>**JEP 320** | The Java 11 change that removed the Java EE and CORBA modules (JAXB, JAX-WS, JAF, Common Annotations…) from the JDK. Code that used them needs them as dependencies. [openjdk.org](https://openjdk.org/jeps/320) | 25 |
| <a id="jpql-hql"></a>**JPQL / HQL** | The query languages of JPA and Hibernate: SQL-like, but over entities (`SELECT a FROM Account a`). Building one with `+` from user input is injection; use bound parameters. | 16 |
| <a id="junit-4-vs-5"></a>**JUnit 4 vs 5** | JUnit 4: `org.junit.Test`, `@Before`, `@RunWith`, `Assert.assertEquals`. JUnit 5 (Jupiter): `org.junit.jupiter.api.Test`, `@BeforeEach`, `@ExtendWith`. Both run on the JUnit Platform. [JUnit](https://docs.junit.org/current/user-guide/#migrating-from-junit4) | 7 |
| <a id="layering"></a>**Layering** | Controller → service → repository, each with one job: HTTP, business rules, data. A controller that calls the repository directly skips a layer. | 3 |
| <a id="legacy-marker"></a>**Legacy marker** | A sign of an older codebase: `javax.*` imports, `WebSecurityConfigurerAdapter`, getter/setter DTOs, JUnit 4, `@MockBean`. | 6 |
| <a id="liveness-readiness-probe"></a>**Liveness / readiness probe** | Health checks a platform calls to ask "is the app alive?" and "can it take traffic?". Boot 4 switches them on by default under `/actuator/health`. | 29 |
| <a id="lockfile"></a>**Lockfile** | `gradle.lockfile`: the exact version of every library, direct and [transitive](#transitive-dependency), so a scanner (and a reviewer) can see what ships. Regenerate with `./gradlew dependencies --write-locks`. [Gradle](https://docs.gradle.org/current/userguide/dependency_locking.html) | 8 |
| <a id="log-injection"></a>**Log injection** | Untrusted input containing line breaks that forges extra log lines. Fix: replace `\r`/`\n` in caller-supplied values before logging. | 18 |
| <a id="log4shell"></a>**Log4Shell** | CVE-2021-44228: a critical remote-code-execution hole in Apache Log4j 2's `log4j-core` (December 2021). Fixed, with its follow-up CVEs, in 2.17.1 and later. [Apache](https://logging.apache.org/security.html) | 27 |
| <a id="lost-update"></a>**Lost update** | Two transactions read the same row, both change it, and the second commit silently overwrites the first. Fixed with optimistic locking. | 20 |
| <a id="lts"></a>**LTS** | Long-term support: a Java release (11, 17, 21, 25) that vendors maintain for years. Services should run on an LTS. | 13 |
| <a id="masking"></a>**Masking** | Showing only part of a sensitive value, e.g. an account number as `****1234`, in responses and logs. | 20–23 |
| <a id="maven"></a>**Maven** | The other common Java build tool. It reads a `pom.xml` and runs a fixed sequence of phases (`compile`, `test`, `package`, `verify`…). [maven.apache.org](https://maven.apache.org/what-is-maven.html) | 24 |
| <a id="maven-wrapper"></a>**Maven Wrapper** | `./mvnw`: a script in the project that downloads and runs the exact Maven version the project expects, like the [Gradle wrapper](#gradle-wrapper). [Maven](https://maven.apache.org/tools/wrapper/) | 24 |
| <a id="mock"></a>**Mock** | A fake object (Mockito `@Mock`, Spring `@MockitoBean`) that returns what the test tells it to, so you test one class alone. [Mockito](https://javadoc.io/doc/org.mockito/mockito-core/latest/org.mockito/org/mockito/Mockito.html) | 4 |
| <a id="mockmvc"></a>**MockMvc** | Sends fake HTTP requests to your controllers inside a test, without starting a server. [Docs](https://docs.spring.io/spring-framework/reference/testing/mockmvc.html) | 5 |
| <a id="multi-project-build"></a>**Multi-project build** | One Gradle build with several projects (services, libraries) listed in `settings.gradle.kts`. Each has its own `build.gradle.kts` and is addressed by a path like `:services:payments`. [Gradle](https://docs.gradle.org/current/userguide/multi_project_builds.html) | 27 |
| <a id="multi-stage-build"></a>**Multi-stage build** | A `Dockerfile` with several `FROM`s, where only the last stage's files end up in the shipped image (e.g. compile with a JDK, ship with a JRE). [Docker](https://docs.docker.com/build/building/multi-stage/) | 28 |
| <a id="non-root-user"></a>**Non-root user** | An ordinary account inside the container (`USER` in the `Dockerfile`), so a compromised app can't change system files. [Docker](https://docs.docker.com/build/building/best-practices/#user) | 28 |
| <a id="object-identity-vs-equality"></a>**Object identity vs equality** | `==` asks "the same object?"; `.equals()` asks "the same contents?". Compare strings with `.equals()`. | 2 |
| <a id="openrewrite"></a>**OpenRewrite** | A tool that rewrites code with recipes, e.g. `UpgradeSpringBoot_3_5`. Run a dry run, read the patch, then apply. It doesn't catch everything. [Docs](https://docs.openrewrite.org/running-recipes/getting-started) | 11 |
| <a id="optimistic-locking"></a>**Optimistic locking** | Detecting that two requests changed the same row at once: each update checks the row's [version](#version) hasn't changed since it was read; the loser fails instead of overwriting. [Spring Data JPA](https://docs.spring.io/spring-data/jpa/reference/jpa/locking.html) | 20–23 |
| <a id="optional"></a>**`Optional`** | A box that may be empty, returned by `findById`. Open it with `orElseThrow(...)`, never `.get()`. See [Java idioms](java-idioms.md#optional). | 1 |
| <a id="osv"></a>**OSV** | Open Source Vulnerabilities: a free database and API of advisories by package and version. `tools/OsvCheck.java` queries it. [osv.dev](https://osv.dev/) | 8 |
| <a id="output-capture-extension"></a>**`OutputCaptureExtension`** | A Spring Boot test extension that captures console and log output so a test can assert on it (`CapturedOutput`). | 18 |
| <a id="owasp-top-10"></a>**OWASP Top 10** | The ten most critical web-application security risks (2025 edition). Our [cheat sheet](owasp-top-10-cheatsheet.md) maps them to the days. [OWASP](https://top10.owasp.org/2025/) | 8 |
| <a id="ownership-check"></a>**Ownership check** | Checking that the logged-in user owns the record they asked for, in the service, from the authenticated user. The fix for IDOR. | 15 |
| <a id="patch-bump-vs-line-jump"></a>**Patch bump vs line jump** | Tomcat 9.0.83 → 9.0.123 is a patch bump (low risk, fixes only). Spring Framework 5.3 → 6.x is a line jump: a migration. | 9 |
| <a id="pbkdf2"></a>**PBKDF2** | A deliberately slow, [salted](#salt) password-hashing function. Stored as `{pbkdf2}…` via `DelegatingPasswordEncoder`. [Spring Security](https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html) | 17 |
| <a id="pii"></a>**PII** | Personally Identifiable Information: names, account numbers, emails… Keep it out of logs and error messages; [mask](#masking) it where it must appear. | 20–23 |
| <a id="pom"></a>**POM** | `pom.xml`, Maven's build file ("Project Object Model"): the project's name, its dependencies and plugins, written in XML. | 24 |
| <a id="problem-detail"></a>**Problem detail (RFC 9457)** | The standard JSON error body: `type`, `title`, `status`, `detail`, `instance`, plus extras like our `errors`. Spring: `ProblemDetail`. [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457) · [Spring](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-ann-rest-exceptions.html) | 1 |
| <a id="profile"></a>**Profile** | A named set of settings switched on at start-up, e.g. `dev` loads `application-dev.properties` (`SPRING_PROFILES_ACTIVE=dev ./gradlew bootRun`). [Docs](https://docs.spring.io/spring-boot/reference/features/profiles.html) | 10 |
| <a id="re-scan"></a>**Re-scan** | Running the vulnerability scan again after a change, and comparing with the earlier totals. "Upgraded" isn't "done" until you have. | 12 |
| <a id="record"></a>**Record** | A short immutable data class: `record TransferRequest(Long toAccountId, BigDecimal amount) {}` gives a constructor, accessors, `equals`, `hashCode`, `toString`. Java 16+. [Oracle](https://docs.oracle.com/en/java/javase/25/language/records.html) | 0 |
| <a id="refactoring"></a>**Refactoring** | Improving the design without changing behaviour. Prove it by running the same checks before and after each step. | 3 |
| <a id="repository"></a>**Repository** | The data layer: an interface extending `JpaRepository` (`AccountRepository`). Spring Data writes the implementation, including query methods like `findByUsernameAndCurrency`. [Docs](https://docs.spring.io/spring-data/jpa/reference/repositories/query-methods-details.html) | 0 |
| <a id="request-fingerprint"></a>**Request fingerprint** | A summary of what a request means (from, to, amount), used to tell a genuine retry from a different request sent with the same idempotency key. | 21 |
| <a id="risk-acceptance-record"></a>**Risk-acceptance record** | The written form of an [accepted risk](#accepted-risk): which finding, why it isn't fixed now, who owns the decision, and when it will be looked at again. Many organisations require one, signed off, for every scanner finding that isn't fixed. | 26 |
| <a id="role"></a>**Role** | A named group of permissions (here `CUSTOMER`, `TELLER`). `hasRole("TELLER")` checks for the authority `ROLE_TELLER`. | 14 |
| <a id="rollback"></a>**Rollback** | Undoing every change a [transaction](#transaction) made, because something failed. `@Transactional` rolls back on unchecked exceptions by default. | 19 |
| <a id="rosetta-2"></a>**Rosetta 2** | Apple's translator that lets Intel (x86_64) programs run on Apple Silicon Macs. Used on Day 25 because there's no native Apple Silicon build of Temurin 8. | 25 |
| <a id="rounding-mode"></a>**Rounding mode** | How `BigDecimal` drops digits. `HALF_EVEN` (banker's rounding) rounds ties to the even neighbour: 2.345 → 2.34, 2.355 → 2.36. [Oracle](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/math/RoundingMode.html) | 20–23 |
| <a id="safe-http-method"></a>**Safe HTTP method** | A method that must not change data: `GET`, `HEAD`, `OPTIONS`. Browsers, crawlers and link previews send GETs freely. [MDN](https://developer.mozilla.org/en-US/docs/Glossary/Safe/HTTP) | 2 |
| <a id="salt"></a>**Salt** | Random bytes mixed into each password before hashing, so equal passwords get different hashes and precomputed tables don't work. | 17 |
| <a id="sarif"></a>**SARIF** | Static Analysis Results Interchange Format: the OASIS-standard JSON format most code scanners export, so one report can be read by any tool. [OASIS](https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/sarif-v2.1.0-errata01-os-complete.html) | 26 |
| <a id="sast"></a>**SAST** | Static Application Security Testing: a tool that reads source code, without running it, looking for patterns of known weaknesses, e.g. SonarQube, Checkmarx, Veracode, Semgrep. | 26 |
| <a id="sca"></a>**SCA** | Software Composition Analysis: a tool that lists the libraries you ship and matches them against advisories, e.g. Snyk, Dependabot, OSV-Scanner. What we did by hand on Day 8. | 26 |
